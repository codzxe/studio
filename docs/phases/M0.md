## Reproduction

```sh
export PATH="$HOME/.cargo/bin:$PATH"
cd editor
cargo xtask web                     # profile-true release: thin LTO, codegen-units=1, wasm-opt -O2
cp -r target/web/dist/. ../apps/web/public/editor/
```

This is the recipe that produced the committed 2026-10-24 dist (Rust 1.99.1,
wasm-bindgen-cli 0.2.129, wasm-opt 125 on PATH; on the 4 GB box prefix
`CARGO_BUILD_JOBS=1` if a parallel rustc OOMs). The 2026-10-22 chunked
`codegen-units=16` workaround (`scripts/build_editor_web.sh`, resumable `-j1`
build) remains in-tree for RAM-constrained boxes — it produced the superseded
76.2 MB artifact and no longer matches the committed dist.
