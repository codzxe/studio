### Web build of the real editor (M0.3, the former blocker)

- Toolchain on this box: Rust 1.99.1 (rustup), `wasm32-unknown-unknown`,
  `wasm-bindgen-cli` 0.2.129 built **from source** (the musl prebuilt OOM-kills on
  this wasm; glibc build handles it — see `editor/UPSTREAM.md` Build notes).
- The full 656-crate graph compiles clean for wasm32 release: **zero errors**; the only
  warning is upstream's own `pointer_wrap.rs` dead-code note (pre-existing, untouched).
- Dist: `cargo xtask web` → `editor/target/web/dist`, copied to
  **`apps/web/public/editor/`** and committed (D-17 dist policy).
  - `effectcraft_web_bg.wasm` **76.2 MB** uncompressed, **14.5 MB brotli q8**

    `codegen-units=1`. A re-tuned rebuild (cg1 + wasm-opt) is owed on a bigger CI
    box; measured numbers and the cause are recorded in
    [`docs/performance.md`](../performance.md) per §6.

## What is honestly not proven here

  `cargo xtask wasm`): the host debug+incremental build does not fit on the 9.9 GB
  disk next to the committed wasm artifacts (disk filled at 100% twice). The wasm
  release compile gate covers the whole patched tree with zero errors; the
  label-sensitive suites (engine menus/i18n catalogs) must run on a ≥ 32 GB CI box.
  Follow-up tracked as the pin-bump gate in `editor/UPSTREAM.md`.
- **Editor opens at `/editor/` in a browser** (COOP/COEP, no console errors): the dist
  is committed and the serving plumbing (headers, trailing slash, dev proxy) is in
  `apps/web/next.config.ts` per the W-R5 audit, but this box has no browser/display.
  First browser verification is owed to the M3 E2E on staging.
- LiteLLM chat completion from a script (M0.5 item): still owed — no live model env.
- CI skeleton (M0.6): `.github/workflows` is still absent (gap/platform.md finding);
  the repo-token `workflow` scope is needed to enable the staged workflows.

## Reproduction

```sh
export PATH="$HOME/.cargo/bin:$PATH"
cd editor
CARGO_BUILD_JOBS=1 CARGO_PROFILE_RELEASE_CODEGEN_UNITS=16 \
  bash ../scripts/build_editor_web.sh        # chunked, resumable (2-core/4 GB box)
cargo xtask web                              # with the same env: dist assembly
cp -r target/web/dist/. ../apps/web/public/editor/
```
