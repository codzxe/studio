## Integrator findings closed at closeout (pre-existing, surfaced by the fleet)

1. **Ledger settle double-deduction (money bug, pre-M4)** — `planSettlement`
   refunded `outstanding − commit` while the reserve had already deducted N
   and the commit deducted M on top: every completed run charged 2×M − … net
   (E2E: balance 98 where 99 is doc-correct; db integration: 64 vs 82).
   FIXED: settle now releases the FULL hold (`refund = outstanding`;
   D-20). Unit + integration + E2E expectations updated and green.
2. **Leases integration test FK violation (pre-M4 test bug)** — fixture used
   a `usr_other` id with no `user` row. FIXED with a real fixture user.
3. **Run-record step status vocabulary mismatch (pre-M4)** — DB writers emit
   `running`/`success`, the wire vocabulary is `started`/`succeeded`;
   everything surfaced as `skipped`. FIXED with a one-place mapper
   translation in `runs.ts`.
4. **F-1 prototype pollution (M4-N HIGH finding)** — FIXED same day (see
   M4-SAFETY.md §2; boundary + depth defenses, both test-pinned).
