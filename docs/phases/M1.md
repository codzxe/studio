  palette + rail navigation are unit-tested; the responsive-width and
  keyboard-journey proofs are browser proofs that have never run (no

## Gaps / owed (honest — matching W1-A7's milestone audit)

1. **No Playwright journey spec at all** for "sign up → create workspace →
   invite → accept → role gate": `apps/web/e2e/` holds `chat.spec.ts`,
   `m5-agent-edits.spec.ts`, `m7-collab.spec.ts`, `m8-renders.spec.ts`,
   `m9-visual.spec.ts`, `m9-axe.spec.ts` — no M1 spec. Compounding this,
   `.github/workflows/` does not exist repo-wide, so even authored specs have
   never run in CI.
2. **Email verification is disabled** — the gateway has no mail transport;
   `emailAndPassword` is enabled with no verification enforcement
   (`packages/db/src/auth.ts:134`); the `(auth)/verify-email` surface degrades
   honestly. The owed fix is an SMTP/Resend seam (W1-A7 TOP-20 #14).
3. **Invite emails are links-only** — `routes/invites.ts` mints the invitation
   and returns it; nothing is delivered (the in-code comment says a refused
   invite "must not consume a seat or send mail"; accepted invites equally
   send nothing). Acceptable v1, stated here so it is not mistaken for
   delivery.
4. Minor, observed while re-running evidence: one pre-existing red exists in
   the web settings suite *outside M1's surface* —
   `apps/web/src/components/settings/models-preferences-view.test.tsx`
   ("auto-apply degrade copy", 1 of 13; deterministic on this box). Recorded
   for the M5/D-22 owner; deliberately not touched by this docs-only wave.
