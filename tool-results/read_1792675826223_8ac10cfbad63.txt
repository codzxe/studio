     1→     1→/**
     2→     2→ * The deterministic fake editor (task W1-d): an in-memory implementation of the
     3→     3→ * `window.effectcraft` surface for unit tests and E2E fixtures. Also the basis
     4→     4→ * for the later Playwright mock mode: install the returned object as
     5→     5→ * `window.effectcraft` in a test page and drive it with `script()`.
     6→     6→ *
     7→     7→ * It mirrors the verified upstream semantics, not just the shape:
     8→     8→ * - `request` rejects with plain strings (editor/apps/effectcraft-web/src/api.rs).
     9→     9→ * - `addFile` keeps only the last path segment of the name
    10→    10→ *   (`editor/apps/effectcraft-web/src/files.rs` `path_for`).
    11→    11→ * - `engine.batch` resolves `$N.key` references, rolls back a failing atomic
    12→    12→ *   batch, and folds the run into ONE undo step whose label is the batch label
    13→    13→ *   (editor/crates/engine/src/commands/batch.rs).
    14→    14→ * - `edit.undo`/`edit.redo` return `{undone}`/`{redone}` labels;
    15→    15→ *   `edit.history.list` returns `{states, current, branches}` — the fake's
    16→    16→ *   history is linear (branches: 0) and ids are positional (`s0`, `s1`, …)
    17→    17→ *   instead of upstream's content-keyed hex ids; labels are the step that made
    18→    18→ *   each state, the oldest state being "Original".
    19→    19→ * - Error strings use the verified upstream formats: "unknown command `x`",
    20→    20→ *   "invalid parameters for `cmd`: …", "no active composition",
    21→    21→ *   "no composition x", "no composition is open", "select a layer first",
    22→    22→ *   "nothing to undo", "nothing to redo".
    23→    23→ * - Command registry ids/labels/menus/shortcuts are copied from the upstream
    24→    24→ *   spec registrations (see comments for sources).
    25→    25→ *
    26→    26→ * Approximations (documented divergences): `renderFrame` returns a constant
    27→    27→ * 1×1 transparent PNG stub; `editor.state.times` is comp seconds (upstream
    28→    28→ * serializes ticks); `project.summary` items are the comps only (the fake has
    29→    29→ * no separate footage/solid items); no UI element registry (`ui.elements`,
    30→    30→ * `ui.click`, `ui.key` are rejected as unknown methods).
    31→    31→ */
