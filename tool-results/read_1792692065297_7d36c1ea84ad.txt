   301→Corrections to the seams above, discovered while building:
   302→
   303→1. **Step-cap env is `CHAT_MAX_STEPS`** (`env.agent.chatMaxSteps`), not
   304→   MAX_MODEL_STEPS. Same for D-16's stale `MODEL_BASE_URL_*` parenthetical —
   305→   the real runner config is `env.litellm.{baseUrl,apiKey,virtualKey}`.
   306→2. **Gateway route mounts live in `services/gateway/src/app.ts` (`buildApp`)**,
   307→   NOT `src/index.ts` (which only wires env/runner/startup).
   308→3. **`layer.tree` is PER-LAYER** (`{ layer?, comp?, depth?, time? }`; `layer`
   309→   defaults to the FIRST selected layer — a bare `{comp, depth}` silently
   310→   drops all but one selected layer). Verified against
   311→   `editor/crates/engine/src/commands/query.rs` + fake. Consequences:
   312→   - `studio.list_layers` = `comp.info {comp}` (authoritative layer list) +
   313→     per-layer `layer.tree {comp, layer, depth}` (concurrency 4, `tree: null`
   314→     on per-item failure).
   315→   - `comp.info` params: `{ comp? }` (id or name, default active).
   316→   - `prop.get` params: `{ layer?, path }` (`path` required).
   317→   - `edit.history.list` params: `{}`; result `{states, current, branches}`.
   318→   - `ui.inspect.time` is raw comp seconds → `timecodeLabel` formats mm:ss.d.
   319→4. **`studio.plan_edit` is fully server-side** (runner emits BOTH tool.started
   320→   and tool.result for it; the client executor MUST skip it — it does, by
   321→   name). Client tools: exactly get_context / list_layers / get_properties /
   322→   render_preview. The ChatController must never post tool.result itself.
   323→5. **api-client `chat.stream`/`streamChat` already owns the §8.4 reconnect
   324→   loop**: same idempotencyKey re-POST + `Last-Event-ID` cursor, backoff
   325→   1/2/4/8→30s, auto-pause after 3 attempts (`onPause`), manual
   326→   `reconnect()`, fused `cancel()` = POST /runs/:id/cancel + reader abort.
   327→   ChatController maps callbacks → state; it does not re-implement retry.
   328→6. **Tool-event body** (POST /v1/runs/:id/events, strictObject):
   329→   `{ type: "tool.result", toolCallId, result }` — result may be data or
   330→   `{ error: <CODE>, message }`; idempotencyKey `toolresult:<runId>:<toolCallId>`.
   331→7. **Model entitlements wire**: `GET /v1/models` → `Ok({plan, models:[{id,
   332→   tier, use, creditsPer1kInput, creditsPer1kOutput}]})` (no allowedPlans
   333→   leaks); `client.models.list()`. Off-plan chat POST → `MODEL_NOT_ENTITLED`
   334→   (403 envelope). Trial ⇒ exactly [studio-fast] (model picker shows one
   335→   option; the picker must render gracefully for single-model plans).
   336→8. **Credits event**: `{reserved, committed, balance}` with committed
