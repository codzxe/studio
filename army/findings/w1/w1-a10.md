## Notes
- **No UPSTREAM (graphite) leftovers in scope.** Zero matches for graphite/URLs/repo paths in editor/crates/{gpu,render}/src. "After Effects"/"Photoshop" doc mentions are semantic-parity documentation for an AE-style engine (the product's purpose), not clone leftovers.

Removal is an engine-fork decision (or upstream rename), not a per-file fix — fix wave should treat engine-internal `effectcraft` naming as by-design and confine action to the disk-cache default.
