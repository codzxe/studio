## Notes
1. **Missing bundled fonts (build-breaking as checked out):** `editor/assets/fonts/` is absent (only `assets/app-icon` exists; no .ttf/.otf anywhere under editor/), yet `text/src/fonts.rs:21-27` and `ui-egui/src/theme.rs:321-324` `include_bytes!` those exact paths, and `editor/NOTICE:15-17` + `ATTRIBUTION.md:12-18` list them (7 TTFs + OFL-Inter/OFL-NotoSerif/OFL-JetBrainsMono). If this is just binary-stripping in the audit snapshot, ignore; otherwise restore the fonts from the pinned upstream commit before any build/re-pin gate (`cargo test --workspace` per UPSTREAM.md).
2. **EffectCraft naming is deliberate in part:** per ADR-0006 and editor/patches/README.md, technical identifiers are stable across debrand patches — `effectcraft-*` crate names, the `.ecproj` root, the `window.effectcraft` bridge — so the hundreds of `use effectcraft_*` imports across S101–S110 are NOT renamable findings (reported once here, not per line). The genuinely actionable EFFECTCRAFT items are the script-visible strings the debrand pass did not cover: `app.version` "26.0 (EffectCraft …)" (runtime.rs:222), the network/socket error strings (runtime.rs:463, socket.rs:44), and the whole BridgeTalk/`$.os`/`File.fs` self-identification asserted in tests_evalfile.rs (prelude.js:141-282). The fix wave should decide whether "marks never appear in the commercial UI" extends to the scripting surface our agents drive.
3. **Fonts, per the mission:** every non-SaaS font reference is flagged. Summary: bundled = Inter (×5), Noto Serif (upstream's choice; UPSTREAM/HARDCODED) + JetBrains Mono (ours, fine). `DEFAULT_FAMILY = "Inter"` is the highest-impact single line — it reaches every new text layer and every missing-font fallback, and pairs with the out-of-scope `TextDoc` default (`keyframe/src/text_doc.rs:457` `font: "Inter"`, flagged here for the S115/S116 owner). The CJK/Indic/Arabic/Hebrew/Thai and METRIC_ALIASES tables are functional fallback data, kept low on purpose.
4. **Clear-all cache eviction is a recurring pattern** (expr/runtime.rs:264 scripts, expr/sample.rs:73 rendered buffers, text/lib.rs:68 outlines, text/variable.rs:99 varied outlines, text/layout.rs:423 feature_substitutes) — each causes a mass-recompute spike at the cap; layout_rich's own cache (layout.rs:1076-1082, evict oldest quarter at 512) is the in-repo model to copy.
5. **The +2/+4 render-buffer padding** is hardcoded in four places across three crates (render/shapes.rs:611-613 source; render/text.rs:960-962; script/model.rs:669; expr/host.rs:459-463) — one shared constant in the render crate fixes all four.
6. `app.executeCommand` positional ids (model.rs:52) only work today because Undo is special-cased in prelude.js; any AE script using other documented command ids (e.g. 17 Redo, 200 New Project) runs an arbitrary command — worth a wave of its own since it affects every imported .aep script.
7. `variable::intern` (per-glyph mutex + linear scan + unbounded growth under animated axes) is the one finding I'd fix before any long render/export with Variable Font Axes animation.
