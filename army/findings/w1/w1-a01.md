## Notes
1. **Systemic EffectCraft rename (the fix wave must plan it, not patch per-line).** `effectcraft` appears ~724 times in ui-egui/src alone: crate names `effectcraft_engine`, `effectcraft_gpu`, `effectcraft_color`, `effectcraft_host`, `effectcraft_time`; the type `EffectcraftApp` (lib.rs:262); thread names `ec-audio-feed` / `ec-expression-diagnostics` / `ec-frame-{i}`; viewport ids and temp filenames (findings above); the app crate `apps/effectcraft`. The user-visible brand is already "Studio" (e.g. menus.rs:860 `format!("Studio: {n} …")`, native_menu tests "Skrýt Studio"), so code identifiers lag the product. A rename is a coordinated Cargo + type + string sweep; the strings in viewport ids (`effectcraft-panel-window`, `effectcraft-video-preview`) silently churn egui state once, harmless but worth doing in the same release. The `.ecproj`/`.ecprojx`/`.ecpreset`/`.ectemplate` extensions are the riskiest rename (saved files in the wild); recommend a read-compat shim if renamed.
2. **No graphite/upstream-URL leftovers in these scopes.** Community links are config-driven (`effectcraft_engine::links::DISCORD/GITHUB/APP_PAGE`, header.rs:190-210, empty = hidden), credits' `https://github.com/{login}` links are our contributors, icons are declared-and-tested original work. The one genuine leftover asset set is the unused `artcraft-*` brand files (header.rs finding).
3. **AE-trademark panel names** (`LumetriScopes` "Lumetri Scopes", `ContentAwareFill` "Content-Aware Fill", `EssentialGraphics`, `MediaBrowser`) are deliberate After-Effects-parity features with their own implementations ("our own panel" comments, dock.rs:51-54) — no upstream-clone issue, but flag for product/legal review since they are Adobe marks in a shipped UI.
4. **Stubs are honest, not fake-success.** Beyond the Project-clipboard arm (S009), `panels/mod.rs::show` dispatches all 36 panels to real implementations — no canned-data or fake-success arms found in these scopes; the two `placeholder()` fns are dead code, not live stubs.
5. **i18n gaps** (owned by S013+ scopes, listed here because found in these files): credits.rs table headers/labels ("Company", "Model", NameMode/SortKey labels), header.rs:620/:634 ("Record Options...", "Follow-Through..."), native_menu.rs Services chain (finding above) — all English-locked while neighbors use `tr()`.
6. **Verified non-issues** (checked, don't re-report): `Frames::request_with` revision-dropping and `Queue::best` ordering match their tests; `advance_playback` audio-clock/hold logic consistent with #595/#208 comments; `encode_png`/base64 hand-rolled codecs match RFC vectors; `stack_bodies`/`resize_stacked` hostile-input tests pass by construction; `automation`/`menu_keys`/`gpu_failure`/`pointer_wrap` clean.
