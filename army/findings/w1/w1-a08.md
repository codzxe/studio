## Notes
- **EFFECTCRAFT is systemic here, not per-file.** Every one of my 48 scope files imports or mentions the `effectcraft-*` crate family: 355 case-insensitive `effectcraft` tokens across 57 files in `crates/effects/src` alone (`use effectcraft_keyframe::Value`, `effectcraft_project::ParamUi`, `effectcraft_raster::Image`, `effectcraft_color`, `effectcraft_track`, `effectcraft_segment`, doc comments naming `effectcraft-gpu` kernels, and the test command `cargo test -p effectcraft-effects`). This is the vendored-upstream crate naming (editor/Cargo.toml `repository = "https://github.com/storytold/effectcraft"`, UPSTREAM.md pin), so removing it means one central workspace-wide crate rename (Cargo.toml package names + every `use`/path, `RUST_LOG`-style defaults if any, doc commands like the two flagged above) — do NOT rename per-file. Distinctive/user-visible instances are the individual findings above (menus/tests.rs:143 command, doc_path/tests.rs:66 temp prefix, preset JSON format/notes strings, sample-script headers, LUMETRI_LOOKS, the `ec.*` id namespace).
- **The `ec.*` effect-id namespace is persisted data.** Effect instances in saved projects are keyed by ids like `ec.blur.gaussian`; the preset JSONs reference them and `catalog.rs` documents them as the public address format. A rename must ship with an alias/migration layer — `migrate.rs` (EFFECT_NAME_ALIASES, PARAM_ID_ALIASES) plus the engine's saved-project loader is the natural home; the same applies to keylight's `KEYLIGHT_ALIASES` pattern which already does name-only aliasing. Coordinate with the `.ecproj`/`.ecpreset` decision from w1-a01 (S008) and w1-a04's shortcut-format-tag finding.
- **Upstream issue references (UPSTREAM, LOW) — full inventory in my scopes** (all in comments/tests documenting fixed regressions): parenting_3d_position.rs:490 (#1010, #1020); catalog.rs:101,205 (#1195); channel3d.rs:761,899 (#473); color3.rs:1000 (#1656); color_fx.rs:48,1202 (#681 — also names the external "kasper9n" AE oracle), :1230,1263 (#1463); generate.rs:47 (#1063), :141 (#1381); distort2.rs:360 & distort3.rs:1151 (#659); distort4.rs:675 & migrate.rs:242,519 (#1194); migrate.rs:240,502 (#514), :347 (#227); noise3.rs:125,147,634 (#259), :433,580 (#939); misc/generate2/generate3/sim-era refs (#313/#397/#410/#535/#536/#1181 appear elsewhere in the crate outside my scope files). ~25 distinct issue numbers repo-wide.
