## Notes
- The three top-priority fixes: (1) the root `Caddyfile` is a sandbox leftover open proxy — remove; (2) `check-licenses.mjs` silently skips `services/*`, so the gateway's riskiest deps (stripe/better-auth/aws-sdk) are un-gated; (3) `sweeps.ts` requeueStale branch-2 terminal-fails exhausted renders with no ledger refund → permanent credit hold when the last attempt crashes (gateway reconciliation is report-only, "zombies never auto-released").
- Two money-window bugs in pipeline.ts: the post-`markCompleted` `renders.get` (:363) is the only fallible call before `ledger.settle` and is not protected — a transient error there leaks the hold.
- EFFECTCRAFT rename blast radius inside my scopes: env var `EFFECTCRAFT_CLI_PATH` (config env.ts is the owner — other agent), binary name `effectcraft-cli` (worker tests harness + smoke scripts + root package.json `editor:cli` script, not my file), dist filenames `effectcraft_web.js`/`effectcraft_web_bg.wasm` (dev-ready.mjs boot check, infra/caddy/Caddyfile immutable whitelist, infra/caddy/Dockerfile brotli hint), `window.effectcraft` global (e2e-probe-editor.mjs), and the `.ecproj` format identifier (hydrate.ts, harness fixture path, round10-apply-probe.mjs:21 `apps/web/demo-project.ecproj`). Recommend one shared constants module for binary name + dist filenames so no scope hand-copies them again.
- Ops-scripts family: 17 scripts hardcode `/home/z/my-project` and 4 default their base URL to production `https://motiongra.vercel.app` (they sign up real rows in prod DBs); a one-line shared `repoRoot()` + explicit `--prod` gate would fix the whole family.
- The compose `apps`-profile placeholder Dockerfiles and the systemd worker unit are pre-render-wave templates that were never updated after the worker shipped — the native/container deployment paths cannot actually run the worker today (no CLI binary provisioning).
- `hydrate.ts` `MAX_ASSET_PAGES` truncation and `TICKS_PER_SECOND` duplication are cheap, high-value fixes; both have unit-test coverage nearby to extend.
