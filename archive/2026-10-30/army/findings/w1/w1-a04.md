Removing them means a repo-wide crate rename (Cargo.toml package names + every `use`/path) or accepting them as internal identifiers; the fix wave should decide once, centrally — do not rename per-file. `RUST_LOG` semantics are tied to the crate prefix (logging.rs:38 `"warn,effectcraft=info"`), so a rename must update the default filter and docs together.
- Brand drift inventory found in this audit (for the fix wave's branding pass): three names coexist — "Studio" (UI strings, links::APP_NAME, "Studio Log.txt", demo comp "Studio Intro"), "EffectCraft" (crate names, demo title, session-log file names, shortcuts format tag), and upstream "ArtCraft"/"storytold"/"getartcraft.com" (links.rs builders, tests.rs:383-385, editor/README.md, editor/CLAUDE.md:22). `help.sibling`'s default slug is "photocraft" (commands/help.rs:15) — sibling-app cross-promo of the upstream family, out of my file scope but directly fed by links.rs:17-22.

- Engine quality is high overall: `lib.rs:11` denies unwrap/expect/panic/todo in the crate; every fallible path I checked degrades gracefully (offload merge conflicts, disk-cache failures, corrupt projects).
