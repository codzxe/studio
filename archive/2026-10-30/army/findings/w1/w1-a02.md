## Notes
1. **Brand situation (fix wave must decide first).** Three names coexist: English UI + `links::APP_NAME` say **Studio**; crates/types say **effectcraft_*** (`effectcraft_engine`, `effectcraft_text`, `effectcraft_color`, `EffectcraftApp` at ui-egui/src/lib.rs:262); the **Japanese** i18n catalog says **EffectCraft** or **ArtCraft** (S013 findings; every other language keeps "Studio"). Upstream URLs also point at `getartcraft.com` / `github.com/storytold` via `engine/src/links.rs:18,21` (`github_of`/`page_of` — outside my scope, engine crate; the shipped link constants themselves are empty strings and all call sites correctly hide on empty). Renaming the crate namespace is a monorepo-wide mechanical change; the ja catalog rows and `widgets.rs:11 PANEL_TAG` are small, independent fixes.
2. **Systemic i18n gap (highest-volume item).** `i18n/ui.rs`'s `converted_panels_have_no_unwrapped_literals` only scans fixed call shapes (`Button::new("`, `.label("`, …) with string literals. Every scope panel additionally draws English via `painter().text(...)`, `ui.label(RichText::new(var))`, `ui.button(var)`, `ui.radio_value`, `ui.small_button`. Representative lines are listed per scope (MED aggregated); the fix is (a) extend the CALLS/scan or add a painter-text scan, (b) wrap the strings in tr()/tr_args, (c) add catalog rows. ~60+ strings across S014–S020.
3. **Blocking I/O on the UI thread** appears in three bounded forms: user-preset dir rescan every 5 s (effects_presets.rs:253), `fs::metadata` per recent project per frame on Home (home.rs:50), and the flowchart's full graph rebuild per frame (flowchart.rs:282 — also O(e²) edge dedupe). None will hang normally, but all are trivial to cache; the flowchart one is the only quadratic path.
4. **Duplicated fallback pattern**: `Comp::new(1, 1, …).into()` as silent fallback for a missing active comp (effect_controls.rs:1141, layer_panel.rs:96) — the invariant can't break today, but it masks failure if it ever does.
5. **Discord brand color** `0x5865f2` duplicated (dialogs.rs:356, home.rs:293); About banner + Learn/coach card + graph-editor surfaces also carry off-token colors — a small "content surfaces" token pass would remove them all.
6. **Tests are unusually strong** across these files (gradient_editor, fx_widgets, graph, workspace_state, comp_settings, forms, markers_ui, home all have real behavioral tests); only wrong-behavior findings above should be trusted over test coverage — none of the findings above is covered by an existing test.
7. No `todo!()`/`unimplemented!()`/`panic!()` in non-test code in S011–S020; no upstream (Graphite/graphite-editor) references found in scope files; the "After Effects"/"Adobe" mentions are deliberate product-parity wording, and "upstream" in i18n/effects.rs comments refers to After Effects' effect renames, not the clone repo.
