### S125 — av1enc part 1

- editor/crates/av1enc/src/lib.rs:416 | MED | ALGO | `let mut planes = [rec[0].clone(), Plane::new(0, 0), Plane::new(0, 0)];` | `pick_filter_level` clones the full luma reconstruction and re-runs the loop filter on it for *every* level trial (~6–12 trials/frame incl. cache misses) — at 1080p that is ~25 MB of allocation+filtering churn per frame on top of the final pass. ## Notes
1. **Upstream context (fix wave must read first).** `editor/` is the vendored upstream EffectCraft workspace (pinned per `editor/UPSTREAM.md`, ADR-0006 "editor UI frozen"; only build/integration patches allowed). `effectcraft_*` crate names, `EFFECTCRAFT_CONFIG_DIR`, `EffectCraftData`, the app-icon `ai.storyteller.effectcraft.png`, and the "FilmCraft" codec-crate family (`filmcraft-h264enc/-prores/-aac/-isobmff/-vp9/-opus/-hevc/-av1`) are upstream identity, present in ~all 67 files. The only *product-facing* leaks are the three strings in export/src (webm.rs:185-186, webm_av1.rs:72-73, pipeline.rs:347) — those land in user-downloaded render artifacts and are the ones worth a studio-side patch record in UPSTREAM.md; wholesale renames would break the frozen pin.
2. **Do not "fix" spec mirrors without the oracles.** Several context derivations look odd but are decode-validated by ffmpeg/filmcraft roundtrip tests (e.g. vp9enc `tile.rs` single_ref ctx values, av1enc `writer.rs:515-528` greater1 inference for coefficients ≥ 8, hevcenc `frame.rs:1298-1351` coded_sub_block/DC-sig inference). Any change must re-run `cargo test -p effectcraft-export -p effectcraft-vp9enc -p effectcraft-av1enc -p effectcraft-hevcenc -p effectcraft-opusenc` with ffmpeg installed (tests skip silently without it).
3. **Perf findings are one family.** vp9enc `PhasePlanes` (~45 MB/frame), vp9enc `choose_level` (3× full-luma filter trials + clone), av1enc `pick_filter_level` (up to ~12 luma clones/frame), av1enc `Decider::half`/`load_source`, hevcenc `MeRef` (4 padded planes/frame) and `FrameCoder::snap` churn all stem from allocating constant-sized scratch per frame/CTU/trial. A single fix wave adding reusable buffers to the four encoder structs would address them; suggested order by impact: vp9enc PhasePlanes > av1enc pick_filter_level > hevcenc snap/MeRef.
4. **Unverified externals.** `filmcraft_h264enc::Encoder::delay()` semantics (S123 media_start finding) and the hvc1/av01 muxing details live in the external `filmcraft-*` crates (not in my scopes) — verify `delay()` returns frames before fixing encode.rs:87.
5. All five codec crates and the export/host test suites contain **no** `todo!`/`unimplemented!`, no fake-success arms, no commented-out code blocks, and no dead menus/URLs. Hardcoded constants found are codec-spec constants or documented defaults; the only true config-gap is AAC audio bitrate (S123).
