## Notes
- Scope is test-only code: no production/hot-path logic. **No HIGH findings.** Severity here reflects fix-wave coordination cost, not user risk.
- **`effectcraft` totals: 376 references across the 40 files** (rg count), essentially all `effectcraft_*` crate-name imports/paths. The crates are literally packaged as `effectcraft-*` (see editor/crates/engine/Cargo.toml `name = "effectcraft-engine"`), so per-line enumeration is noise: a scripted workspace-wide rename (Cargo.toml names + `use`/`::` paths + doc comments) removes them all. The MED-severity items are the ones a mechanical rename would *break*: the `EFFECTCRAFT_*` env vars (public contract), the `"effectcraft-template"` manifest format id and `<EffectCraftProject` XML root (persisted file formats needing read-old/write-new migrations), and the `effectcraft::` log-target namespace.
- **Brand inconsistency for the fix wave:** the engine brands itself EffectCraft (crate names, XML root, env vars), while tests_markers.rs:16 uses `https://getartcraft.com` as the product URL and product strings say "Studio" ("outside Studio's limits", tests_limits.rs:56; "a project Studio can open", tests_menu_cmds.rs:1242). Decide the canonical name *before* starting any rename, or the migration will be done twice.
- **Deliberate disabled stubs (do not "fix"):** `file.importVanishingPoint` (always errors with a reason, tests_m137.rs:62-68) and the no-selection stubs `layer.autoTrace`, `layer.sceneEditDetection`, `layer.create`, `track.motion` (tests_menu_cmds.rs:895-898) — these *refuse* rather than fake success (good); the same auto-trace/scene-edit commands become enabled with a footage layer selected (tests_panels.rs:577-579), so they are context-gated, not dead.
- **Untested-by-default paths:** `EFFECTCRAFT_MOBILESAM` / `EFFECTCRAFT_FACE_LANDMARKER` gate the real-model arms of tests_models.rs and tests_face.rs with `else { return }`, so default CI never exercises MobileSAM Roto Brush 3.0 or MediaPipe face tracking. Not a bug, but the fix wave/QA should know these paths only run when the weights env vars are set.
- The three "mystery constants" worth centralizing: `8_467_200_000` (ticks/second, tests_quick_offset.rs:12) — consider exporting a constant from `effectcraft_time`; `100u64 << 30` default disk-cache budget asserted at tests_disk_cache.rs:38; `0x00EC_F022` fuzz default seed (tests_fuzz_open.rs:310 — cute but fine).
- tests_effects.rs:584 fabricates group uids with `1_000_000 + at.children.len()` to build legacy projects — fine for the migration test, but fragile if uid allocation ever reaches that range legitimately.
- No upstream (graphite-editor) leftovers, no URLs to Adobe/upstream repos, no `todo!()`/`unimplemented!()`, no fake-success arms, and no panicking-on-external-input code were found in these 40 files.
