## Notes
1. **Debrand coverage gap (root cause of most findings).** `scripts/debrand_editor.py` (lines 31-38) only rewrites `apps/effectcraft-web/**` plus one xtask icon edit. It never touched `editor/apps/effectcraft` (native), `editor/apps/effectcraft-cli`, `editor/xtask`, `editor/crates/automation|plugin` or the workspace Cargo.tomls — which is exactly where the remaining EffectCraft strings live, and it missed the one functional break (xtask bench "EffectCraft Intro" vs the renamed demo comp "Studio Intro"). The fix wave should extend the debrand script's file list, not hand-edit.
2. **Storage-name renames need migrations, in priority order:** host.js `DIR`/`DB` "effectcraft" (user projects/media — HIGH), `HANDLES_DB` (folder permissions), sw.js cache prefix, `CACHE_ROOT` (plus old-dir cleanup). Per scripts/army/gen_manifest.py's brand-config plan, all of these should flow from the single brand file; breaking stored browser data is acceptable pre-launch only if stated.
3. **Frozen-format ids, not renames:** `ec.` effect-id namespace (stored in .ecproj project files and referenced by CLI bench + QA tests), the `ec_*` wasm plug-in ABI exports, and `EFFECTCRAFT_*` env vars (`CONFIG_DIR`, `CONTROL_PORT`, `REQUIRE_WINRES`) are public/serialized contracts — rename behind compat aliases or explicitly declare them frozen.
4. **S148 deletion-candidate verdict:** the SaaS is web-only (docs/PRODUCT_ARCHITECTURE.md:246; the Next.js app serves `editor/apps/effectcraft-web` dist, and services/worker calls `effectcraft-cli`). Nothing in apps/web or services references the native `effectcraft` desktop binary — its only consumers are editor/README.md download links (getartcraft.com, upstream), packaging/, and assets/app-icon desktop formats. Nothing in `editor/apps/effectcraft` is load-bearing for the web product (the load-bearing pieces live in the web app, the CLI, xtask and the engine crates), so the whole app directory is deletable; `eframe`/`rfd`/`cpal`/`zbus`/`muda`/`objc2*`/`fmv-macos-events`/`winresource` deps exist only for this app and disappear with it.
5. **`icon-256.png`/`icon-512.png` in manifest.webmanifest and index.html are NOT broken refs** — xtask web build copies them from `assets/app-icon/studio/` into dist (xtask/src/main.rs:305-308); the source files exist. Don't "fix" them.
6. Cross-scope couplings the fix wave must keep atomic: audio processor name (host.js + audio-worklet.js), canvas id + glue file names (index.html + worker.js + preflight.mjs + workers.mjs + xtask), auto-save folder match (store.rs:260 + engine AUTOSAVE_FOLDER), MCP serverInfo name (automation crate + harness.rs:26 + cli.rs:231), `window.effectcraft` API name (api.rs docs, index.html, smoke.mjs, effectcraft-web Cargo description).
7. No hardcoded stubs, fake data, or `todo!()` arms anywhere in S141–S150; the only "unavailable" fallback (plugin wasm feature) correctly reports an error rather than pretending success.
