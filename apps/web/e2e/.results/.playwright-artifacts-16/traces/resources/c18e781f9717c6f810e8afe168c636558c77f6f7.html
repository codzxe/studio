Questions, answered

Which browsers are supported?+

Any recent browser with WebGPU or WebGL2: Chrome and Edge 113+, Firefox 121+, Safari 18+. The editor checks capabilities when it loads — if your browser can't run it, you get a rendered preview instead of a broken canvas.

What file formats can I import and export?+

Projects are .ecproj files: import and export the whole project — compositions, layers, keyframes, effects and the render queue intact. Renders export as MP4, ProRes, PNG sequences, GIF or WAV.

Where does my data live?+

Project files and uploaded assets live in your workspace's object storage; every save is an immutable version snapshot, so nothing gets overwritten. Data stays inside your workspace's storage region and is never used to train models.

Which models does the agent use?+

A fast model for everyday edits and a smart model for heavy reasoning, routed per plan. Before a run you see the plan, its risk level and the estimated credit cost — model names and costs are shown up front, never hidden.

Can I use the editor without the agent?+

Yes. The agent is a panel beside the timeline, not a paywall — every manual tool, keyframe and effect works without it. You can hide the panel entirely.

Can I cancel anytime?+

Yes — from billing, in two clicks, no retention flow. Your work is never deleted for non-payment: unpaid workspaces go read-only, not blank.
